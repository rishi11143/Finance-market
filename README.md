# Finance Market Intelligence Terminal

A Bloomberg-inspired financial learning and paper trading platform built with
Next.js and TypeScript.

## Features
- Simulated stock trading (paper trading)
- Technical indicator analysis
- Market trend predictions
- Financial education modules
- Skill assessment quizzes

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide Icons

## Purpose
Designed as an educational platform to practice market analysis and trading
concepts without real financial risk.
